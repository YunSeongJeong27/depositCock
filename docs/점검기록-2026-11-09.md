- 백엔드 테스트 전체 (`./mvnw test`, H2) 266개 통과. 새 테스트 `SellerPhoneAndAdminAccountTest` 4개
  - 가입: 번호 없으면 `PHONE_REQUIRED`, 모양이 틀리면 `PHONE_INVALID`, "010 9876 5432" → 010-9876-5432, 관리자 목록에도 보임. 내 정보: 안 보내면 그대로·바꾸기·틀린 모양 막힘·비우면 지움

  - 관리자 계정 이메일은 못 바꾸고(`ADMIN_EMAIL_FIXED`) 이름은 바꿈
  - 기존 테스트의 가입 요청에 휴대폰 번호를 넣음 (`IntegrationTest.signup`, `M1AuthAndTenantTest`·`SecurityReviewTest`·`ErrorResponseTest`·`SignupOpenTest`)

- 브라우저 (jar 로 실행, V2 가 새 DB 에 적용되는 것 확인): 관리자로 [+ 계정 만들기] → 만들기 → 안내·표에 번호, [정보 수정] → 이름·번호 고쳐 저장 → 표에 바로 반영, 관리자 줄은 이메일 칸이 잠김, 만든 계정으로 로그인 → 내 정보에 번호, 회원가입 화면 휴대폰 칸 (1366·390, 관리자 화면 폰 폭 가로 넘침 없음)
